# References

## Primary reference

**Optimization-based Coordination and Control of Traffic Lights and Mixed Traffic in Multi-Intersection Environments**

Nilesh Suriyarachchi, Rien Quirynen, John S. Baras, and Stefano Di Cairano.

- MERL report TR2023-059, cover dated June 1, 2023.
- American Control Conference (ACC), 2023, pp. 3162-3168.
- [MERL publication and PDF](https://www.merl.com/publications/TR2023-059).
- [DOI: 10.23919/ACC55779.2023.10156306](https://doi.org/10.23919/ACC55779.2023.10156306).
- [BibTeX](references.bib), based on MERL's publication metadata.

This is the project's primary methodological reference. It studies centralized and decentralized MILP coordination of signals and connected automated vehicles in mixed traffic. The repository currently contains planning documents, not an implementation or reproduction.

## Secondary background

Quirynen, Safaoui, and Di Cairano, *Real-time Mixed-Integer Quadratic Programming for Vehicle Decision Making and Motion Planning*, MERL TR2024-123. [Publication](https://www.merl.com/publications/TR2024-123).

This earlier reference concerns individual-vehicle maneuver/trajectory planning and is retained only as background. Its solver-focused evaluation should not be confused with the traffic-efficiency metrics in TR2023-059.
